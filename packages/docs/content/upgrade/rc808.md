**Concerns:** `pushword/flat`

## The deploy excludes every generated output by default

On the model of `static/`, the default excludes now keep `public/assets/`
(yarn build), `public/bundles/` (Symfony assets install) and `public/media/`
(`pw:image:cache`) out of both directions — the remote chain rebuilds them. A
site that does not rebuild one server-side opts back in by overriding
`PUSH_EXCLUDES` without it: the exception lives in the conf, not the rule.
