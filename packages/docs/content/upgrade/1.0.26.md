**Concerns:** `pushword/static-generator`.

## Static exports retain the published homepage

`pw:static` now fails if a full build would remove an existing `index.html` or a
worker cannot load every assigned page. If deleting the homepage is intentional,
remove the old `index.html` from the host's `static_dir` first.

**Sites whose homepage becomes a redirect (e.g. `/` → `/en/`).** It generates no
`index.html`, so every full build fails until you delete the old one by hand.
