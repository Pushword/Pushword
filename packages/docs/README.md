## Features

- The **Markdown source** of the official documentation site.
- Architecture, extensions, media API and editorial guides.
- Edit on GitHub to **improve the docs** (PRs welcome).

## Documentation

Visit [pushword.piedweb.com](https://pushword.piedweb.com).

## The Pushword ecosystem

Pushword is a modular CMS — one [Symfony](https://symfony.com) bundle for the core and one bundle per feature. See the full list and guides at [pushword.piedweb.com/extensions](https://pushword.piedweb.com/extensions).
